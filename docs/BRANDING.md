# PleosFlows branding · 28 October 2026

- Product name: **PleosFlows** (case-sensitive display spelling).
- Tagline: **차량의 움직임을 업무의 흐름으로**.
- Descriptor: **PV5 운영자를 위한 고객 안내·반복 업무 자동화 플랫폼**.
- Product concept: the operator defines a bounded rule, a vehicle event triggers allowed customer guidance, and explicit completion closes sharing and returns to the same run history.
- Positioning is a proposal, not a measured benefit: reducing repeated status checks and manual customer messages is a hypothesis to validate.

## Independent proposal and current scope
PleosFlows is an independent proposal prototype, not an official Kia/Pleos product or partnership. The web UI is not an installed vehicle app. Native SDK, real-car integration, live external service connections and production authentication are not implemented. No real message or vehicle command is sent.

The primary `/` / `/unified.html` route connects two bounded templates, operator configuration, assigned vehicle, scoped customer projection and same-run audit. The earlier studio and other lab executors are separate; a shared visual brand does not make them integrated.

## Compatibility
This release changes names, titles, descriptive copy and package metadata only. API routes, stored IDs, data schemas, permissions, flow logic and on-disk data locations stay unchanged. `MOBFLOW_DATA_DIR`, `mobflow-platform-editor-v1`, `mobflow-fleet-console-v1`, `mobflow-communication-run`, `mobflow-story-run` and `mobflow-story-instance` deliberately retain their old spelling to preserve existing installations and session selections. Test temporary-directory prefixes are internal fixture names, not product branding.

Historical test counts and dates in the documentation remain historical evidence, not a claim that those browser scenarios were re-run in this release.
